# Spext for Gemini CLI

A minimal Gemini CLI extension for the hosted Spext MCP server.

## Tools

- `create_text_share`
- `create_secret_note`
- `create_file_request`

## Install

```sh
gemini extensions install https://github.com/GITHUB_OWNER/spext-gemini-extension
```

No local MCP server or additional dependencies are required.
